# Changelog

## 1.0
- First release.
- Battery for left / right earbud and case (last known value shown when a bud is out of reach).
- Switch Noise cancelling / Ambient sound / Off from the widget or the app.

- Auto-reconnect (3×3 s, 2×5 s, 1×15 s, then waits for Bluetooth).
